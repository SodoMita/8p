# WebP, pumpkin collision, localization

Based on main e2b06b3. Game textures under `assets/textures` are lossless WebP. All 34 original images were compared against their converted files in RGBA and are pixel-identical, including transparent pixels. Screenshots and the application icon remain PNG; the latter is not a game texture. `tools/regen_all.sh` converts its PNG intermediates before generating the localized notes and importing. Texture regeneration requires Pillow with WebP support.

Each pumpkin gets a static, low-poly convex hull following its visual transform, with three reusable shapes (one per mesh variant). The hull is an approximation of the pumpkin body and deliberately excludes the thin stem. This leaves MultiMesh rendering batched. The selftest checks visual instance counts, matching placement transforms, and a physics overlap.

The startup objective, introduction, prompts, touch controls, status messages, pause-camera options and note-reading text use the translation tables. Localized in-world note textures are generated by `tools/gen_notes.py` from the same strings. Chinese UI uses a subset of Noto Sans CJK as a fallback; the corresponding license is in `assets/fonts/`. When adding Chinese strings, regenerate the subset from Noto Sans CJK and run the glyph-coverage selftest. Export presets explicitly include the JSON translation files.

Validation under Godot 4.7.2: English, Russian, Chinese headless selftest each 98/98; headless camera rig 30/30; headless controls 27/27. Existing Godot shutdown resource-leak warnings remain, as does the pre-existing pause/resume `self_list` warning in the controls test. No graphical/mobile/browser export or human playtest was performed in this environment.
